# 코레일 면접 시뮬레이터 · 시우 공방

코레일 2026 하반기 고졸 제한경쟁채용 **[차량 분야 · 부산경남권]** 면접(PT/상황 면접 + 경험 면접)을 실전처럼 연습하는 단일 HTML 게임입니다.

## 실행
`index.html`을 크롬·엣지·사파리로 열면 됩니다. 서버나 API 키가 필요 없습니다.

- **음성 답변**: 크롬/엣지 권장. 처음에 마이크 권한을 허용하세요. 지원하지 않는 브라우저에서는 자동으로 타자 입력으로 바뀝니다.
- 일부 브라우저는 `file://`로 열면 음성 인식이 막힙니다. 그럴 때는 폴더에서 `npx serve .` 또는 `python3 -m http.server`로 띄운 뒤 `http://localhost:...`로 여세요.
- 기록은 브라우저 localStorage에 저장됩니다. 저장이 막힌 환경(시크릿 모드 등)에서도 게임은 정상 동작하며, 그 경우 기록만 남지 않습니다.

## 모드
| 모드 | 흐름 |
|---|---|
| 경험 면접 | 대기실 → 자기소개 → 자소서 기반 + 일반 질문 → 질문마다 꼬리질문 1~2개 → 자기평가 → 마지막 할 말 → 리포트 |
| PT(상황) 면접 | 상황 카드 → 준비 3분(5단계 메모) → 발표 2분 → 꼬리질문 2개 → 리포트 |
| 실전 모드 | PT 면접 → 경험 면접 연속 |
| 오답노트 | 70점 미만 질문이 자동으로 담기고, 재도전에서 80점 이상이면 졸업 |
| 기록 | 스트릭, 최근 14일, 등급 그래프, 상황카드 클리어, 업적, 지난 리포트 |

## 질문·상황 카드·키워드 직접 고치기
`index.html`의 `<script id="game-data">` 블록(파일 앞부분의 **✏️ 편집 영역**)만 고치면 됩니다.

- `CONFIG` — 준비/발표 시간, "너무 짧음" 기준, 오답노트 기준 점수, 등급 컷, 압박 강도별 꼬리질문 수·이벤트 확률
- `KW` — 키워드 사전 (`'대표어|동의어1|동의어2'`, 띄어쓰기 무시)
- `TABOO` — 금기어와 고쳐 말하기 팁
- `STRUCTURES` — STAR / 두괄식 / PT 5단계 구조 체크 단서어
- `EXP_QUESTIONS` — 경험 면접 질문 (`core` = 자소서 핵심, `followUps` = 꼬리질문 트리, `next` = 2단계 꼬리질문)
- `PT_CARDS` — 상황 카드 (`model` = 5단계 모범 발표)
- `ACHIEVEMENTS`, `WAIT_TIPS`

모범 답변의 **[대괄호]** 부분은 본인의 실제 경험·사실(대체 자재 이름, 대회 결과, 실제 증상 등)로 바꿔서 말해야 하는 자리입니다.

## 채점 방식 (오프라인 규칙 기반)
답변 1개 점수 = 키워드 충족 + 구조(STAR·두괄식·PT 5단계) + 시간(30초 미만 짧음 / 적정 / 초과) + 금기어 감점 + 자소서 핵심 연결.
질문 점수 = 본 답변 60% + 꼬리질문 평균 40%, 여기에 자기평가(자신감·논리·일관성)를 10% 반영합니다.
등급: S 90+ · A 80+ · B 65+ · C 50+ · D

※ 실제 코레일 로고·상표는 사용하지 않았습니다. 기업 정보·숫자는 면접 전에 공식 자료로 꼭 확인하세요.
