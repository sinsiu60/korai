# 시우 파티 (Siwoo Party)

한 대의 안드로이드 폰으로 2~4명이 함께 하는 **파티 게임 모음집**입니다. **게임 34종 + 도구 3종** (아래 표).
허브에서 게임을 고르고, 게임이 끝나면 순위대로 모임 점수가 쌓여 "오늘의 왕"을 뽑습니다.
인터넷·광고·계정이 없고, 이미지·사운드 파일 없이 모든 그래픽을 코드(Canvas)로 그립니다.

- 대상: 안드로이드 8.0(API 26) 이상, 32비트 ARM(armeabi-v7a) 저사양 폰 포함
- 화면: **가로 고정**(기기를 어느 쪽으로 돌려도 가로 유지), 전체 화면
- 언어/구성: Kotlin + 커스텀 View(Canvas) (NDK·게임 엔진·Compose·AppCompat 없음, AndroidX 는 목록용 RecyclerView 만)
- 권한: **없음** (인터넷 권한도 요청하지 않음)
- 앱 ID `com.siwoo.party` — 예전 단독 앱 "시우 마블"(`com.siwoo.marble`)과 따로 설치됩니다

## 1. 설치 방법 (APK 직접 설치)

1. APK 파일(`siwoo-party-<버전>-release.apk` 권장)을 폰으로 옮깁니다. (USB, 메신저 "나에게 보내기", 구글 드라이브 등)
2. 폰의 **파일 관리자**(또는 다운로드 앱)에서 APK를 누릅니다.
3. "보안상의 이유로 이 출처의 앱을 설치할 수 없습니다" 같은 안내가 나오면 **설정**을 누르고
   **"이 출처 허용"** 스위치를 켭니다. (= 알 수 없는 출처 허용)
   - 직접 찾아가려면: `설정 → 애플리케이션(앱) → 특별한 접근(특수 앱 접근) → 출처를 알 수 없는 앱 설치`
     → APK를 연 앱(예: 내 파일, Chrome)을 선택 → 허용
4. 뒤로 돌아와 **설치**를 누릅니다.
5. 설치가 끝나면 3번에서 켠 허용을 다시 꺼도 됩니다.

> 디버그 키로 서명되어 있어 Play 프로텍트가 "확인되지 않은 앱" 경고를 띄울 수 있습니다.
> "무시하고 설치"(또는 "세부정보 → 설치")를 누르면 됩니다.
> 디버그 APK와 릴리스 APK는 같은 키로 서명되어 서로 덮어 설치할 수 있습니다.

### APK 받는 곳
- **Actions**: `siwoo-party/` 폴더가 바뀌어 push 될 때마다 자동 빌드되며, 실행 결과 하단
  **Artifacts → `siwoo-party-apk`** (hub-debug.apk / hub-release.apk) 에서 받을 수 있습니다.
- **GitHub Releases**: 커밋 메시지에 `[release]` 를 넣어 push 하거나 Actions → "시우 파티 APK 빌드" → **Run workflow**(release 체크)
  → `siwoo-party-v<버전>-build<번호>` 릴리스에 APK 두 개가 첨부됩니다. 버전은 `hub/build.gradle.kts` 의 `versionName` / `versionCode`.

## 2. 모임 흐름

```
로고 "시우 공방" → 타이틀 "시우 파티" → [시작하기]
   → (이전 모임이 있으면) [이전 모임 이어하기] / [새 모임]
   → 플레이어 설정: 2인/3인/4인 → 이름 + 색(겹치지 않게)
   → 허브
```

### 허브 (가로)
```
┌──────────────────────────────────────────────────┐
│ 시우 파티  최근 [▣][▣][▣]        👑[가람 6점] [나래 5점] [다온 2점] │
│ [전체] [🎲 보드게임] [🃏 카드·두뇌] [⚡ 순발력] [🎯 손맛·타이밍] ┌──────┐ │
│ ─────                                             │ 🎉   │ │
│ 🎲 보드게임 5                                       │ 파티 존│ │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐              │(네온) │ │
│ │ 시우 마블  │ │ 야추 주사위│ │ 땅따먹기  │  ← 카드: 아이콘·이름·소개  └──────┘ │
│ │ 2~4인 차례 🎲│ │ …        │ │ …        │     배지(인원·방식·랜덤 주사위)      │
│ └──────────┘ └──────────┘ └──────────┘                       │
│ [🎲 랜덤 게임] [🛠️ 도구] [플레이어 변경] [설정] [모임 종료]                │
└──────────────────────────────────────────────────┘
```
- **카테고리 탭**: [전체] [🎲 보드게임](금색) [🃏 카드·두뇌](청록) [⚡ 순발력](주황) [🎯 손맛·타이밍](초록). 고른 탭 밑줄이 미끄러지며 이동.
  [전체]는 카테고리별 소제목 아래 카드 묶음. **파티 게임은 탭·[전체]에 나오지 않고 파티 존에만**.
- **카드 배지**: 인원 · 방식(동시/차례) · 시간 · 🎲 랜덤 포함(꺼지면 회색 + 빗금). 오른쪽 위: 지금 인원으로 못 함(어둡게) / 이어하기 / 기기 조건 부족.
- **카드 누르기** → 소개 팝업 [규칙 보기] [시작] (게임 설정이 있으면 [게임 설정]). 처음 하는 게임은 규칙 카드 3장이 먼저.
- **카드 길게 누르기** → 빠른 메뉴: [🎲 랜덤에 넣기/빼기] [규칙 보기]
- **최근 한 게임** 3개 아이콘 → 누르면 바로 소개 팝업
- **플레이어 변경**: 인원을 바꾸면 허브·파티 존 카드와 랜덤 후보 수가 바로 바뀝니다. 같은 이름은 점수를 이어 받습니다.
- **설정**: 연출 속도(모든 게임), 효과음, 게임 후 벌칙, 벌칙 문구 편집, **🎲 랜덤 게임 설정**
- **모임 종료**: "오늘의 왕" 시상대 + 꽃가루 → [새 모임 시작] (점수·저장 게임 초기화)
- 게임 중 **뒤로 가기**: 일시정지 [계속하기] [규칙 보기] [허브로 나가기(확인)] — 중간에 나가면 그 판은 점수 없음 (시우 마블만 이어하기 저장)

### 🎉 파티 존
- 허브 오른쪽 큰 입구 카드(네온 보라·분홍 테두리가 천천히 빛남)를 누르면 화면이 어두워졌다가 네온이 켜지듯 파티 존이 열립니다.
- 짙은 보라 + 네온 분홍·하늘색 테마. 파티 게임 카드에 **"말로 함" / "몸으로 함"** 태그.
- 위 버튼: **[🎲 파티 랜덤]** (파티 게임만, 파티 랜덤 스위치를 따름) **[파티 설정]** **[허브로]**
- **파티 설정**: **점수 반영**(기본 켬 — 끄면 결과 화면에 순위만 보이고 누적 점수에 더하지 않음),
  **게임 후 벌칙**(기본 켬 — 결과 화면 [꼴찌 벌칙 룰렛]), [🎲 파티 랜덤 설정]

### 🎲 랜덤 게임 설정 (설정 → [🎲 랜덤 게임 설정], 파티 존은 [파티 설정] → [파티 랜덤 설정])
- 카테고리별 접이식 묶음(▶ 눌러 펼치기). **카테고리 스위치**를 끄면 그 안의 게임이 전부 꺼지고,
  일부만 켜져 있으면 스위치가 "일부"(가운데 + 줄) 상태. 일부·끔 상태에서 누르면 전부 켜짐.
- **게임별 스위치** (카드를 길게 눌러도 바꿀 수 있음). 기본: 일반 게임 전부 켬, **파티 게임은 허브 랜덤에서 끔**.
  파티 랜덤은 파티 게임별 스위치를 **따로** 가짐(기본 전부 켬).
- 위에 **"현재 인원(N명)으로 랜덤에 올라갈 게임: N개"** 실시간 표시, [전체 켜기] [전체 끄기], **[같은 게임 연속 방지]**(기본 켬 — 직전 게임 제외, 후보가 1개뿐이면 예외).
- 룰렛에 올라가는 조건: **스위치 켬 + 지금 인원 지원 + 기기 조건**(동시 터치 수, 기울기 센서). 각 게임 줄에 빠지는 이유가 주황색으로 표시됩니다.
- 조건을 만족하는 게임이 0개면 룰렛 대신 안내 팝업 + [랜덤 설정 열기]. 후보가 **9개 이상이면 원형 룰렛 대신 세로 슬롯머신**.
- 저장: 앱 내부 SharedPreferences (앱을 다시 켜도 유지).

### 🛠️ 도구
허브 아래 [🛠️ 도구] → 손가락 추첨 · 사다리 타기 · 순서 정하기 (점수와 무관, [← 허브]로 돌아옴). 플레이어 이름·색은 지금 모임에서 가져옵니다.

### 결과 화면과 점수
게임이 끝나면 순위(동점 허용)를 받아 모임 점수에 더하고 결과 화면을 보여 줍니다.

| 인원 | 1위 | 2위 | 3위 | 4위 |
|---|---|---|---|---|
| 2인 | 3 | 0 | | |
| 3인 | 4 | 2 | 0 | |
| 4인 | 4 | 2 | 1 | 0 |

- 동점이면 그 순위의 점수를 **각자** 받습니다 (예: 4인 공동 1위 2명 → 4, 4 / 다음 사람은 3위 1점).
- 결과 화면: 3위 → 2위 → 1위 순서로 시상대 블록이 솟고 이름이 나타남 → 1위에 왕관이 떨어짐
  → 얻은 점수가 각자의 칩으로 날아가고 누적 점수가 올라감
- 버튼: **[다시 하기]**(같은 게임 바로 다시) **[꼴찌 벌칙 룰렛]**(설정 "게임 후 벌칙" 켬일 때, 파티 게임은 파티 설정을 따름) **[허브로]**
- 파티 존 "점수 반영"을 끄면 결과 화면에 "점수 반영 끔"이 표시되고 시상대에 순위만 나옵니다 (기록은 남음).
- **꼴찌 벌칙 룰렛**: 10칸(소형 6·중형 3·대형 1 → 정확히 60/30/10%) → 등급 문구 중 하나가 카드로 뒤집혀 나옵니다.

## 3. 시우 마블

허브에서 열면 플레이어는 허브의 사람들 그대로입니다 (따로 설정 없음).
- 같은 사람들의 끝나지 않은 게임이 있으면 **[이어하기] / [새 게임]**
- 새 게임: **게임 방식** 팝업 — 기본 **15라운드**(모임 시간이 길어지지 않게), 20·30라운드, 최후 1인 + 현실 벌칙 모드 → [시작] → 순서 추첨
- 끝나면 순위 → [결과 보기]로 허브 결과 화면:
  최후의 1인이 1위, 파산한 사람은 **늦게 파산할수록 높은 순위**. 라운드 제한 종료면 살아남은 사람끼리 **총자산 순**(같으면 공동 순위), 파산자는 그 아래.

### 화면 (가로)
```
┌──────┬──────────────┬──────┐
│ P1   │   보드(정사각)  │ P2   │   패널: 말 색·이름·현재 돈·보유 땅 수·총자산·상태
│      │  가운데: 주사위 │      │   현재 차례 패널은 테두리가 천천히 빛나며 살짝 커짐
│ P3   │  + 중앙 문구    │ P4   │   벌칙 지속 효과는 작은 아이콘(주사위1·×2·½·쉼)
├──────┴──────────────┴──────┤
│ 알림 한 줄   [판매] [거래] [턴 종료] [설정] │  ← 행동 바 (현재 차례만, 연출 중 비활성)
└────────────────────────────┘
```
- **주사위는 보드 가운데를 직접 터치**해서 굴립니다. 패널을 누르면 그 사람의 땅·카드 상세, 칸을 누르면 땅값·건설비·통행료 표.

### 시우 마블 규칙
| 항목 | 규칙 |
|---|---|
| 주사위 | 2개의 합만큼 이동. **더블**이면 한 번 더(다시 굴려야 턴 종료 가능), **3연속 더블**이면 즉시 무인도 |
| 턴 종료 | 굴린 뒤 **[턴 종료]**를 눌러야 다음 사람 차례 (자동으로 넘어가지 않음) |
| 월급 | 출발 칸을 지나가거나 도착하면 20만 |
| 빈 땅 | 자동 팝업 없이 칸이 **금색으로 발광** + "터치하여 구매" → 칸을 터치해 구매 카드에서 [구매]. 사지 않고 [턴 종료]하면 포기. 돈이 모자라면 발광은 하지만 [구매]가 비활성화되고 "잔액 부족" |
| 내 땅 | 산 **다음 방문부터** 같은 방식(초록 발광)으로 별장 → 빌딩 → 호텔 한 단계씩 |
| 관광지 | 제주도·여객기·부산·여객선·우주선·서울: 구매만, 건물 불가, 고정 통행료 |
| 남의 땅 | 칸이 소유자 색으로 번쩍 → "통행료 수거!" → 코인이 내 패널에서 소유자 패널로. 통행료 면제권이 있으면 먼저 사용 여부를 묻습니다 |
| 돈 부족 | 전액을 내고 **마이너스**가 됩니다(받는 사람은 전액 받음). 마이너스면 [턴 종료]·주사위 비활성화, [판매]가 빨갛게 깜빡이며 "잔액이 부족합니다. 땅을 판매하거나 거래하세요" |
| 판매 | 내 땅을 여러 장 골라 은행에 판매. **판매가 = 자산 가치(땅값 + 지은 건물 건설비) × 50%** |
| 파산 | 땅·건물을 모두 팔아도 마이너스면 파산 (패널 흑백 + "파산" 도장, 땅은 은행으로) |
| 거래 | 상대를 골라 땅 여러 개 + 돈을 주고받는 제안 → 기기를 넘겨 상대가 수락/거절. **한 턴에 최대 3번** 제안 |
| 황금열쇠 | 16종(벌칙 면제권 포함). 카드가 뒤집히며 공개, 사용한 카드는 덱 맨 아래로 |
| 벌칙 칸 | 7번(아래 줄)·22번(위 줄). 빨갛게 3번 깜빡 → "벌칙 당첨!" → **벌칙 룰렛** (아래 참고) |
| 무인도 | 3턴 갇힘. 더블이면 즉시 탈출, 탈출권 카드 사용 가능 |
| 사회복지기금 | 접수처 칸(15만)·기부 카드로 쌓이고, 사회복지기금 칸에 도착한 사람이 전액 수령 |
| 우주여행 | 다음 턴에 굴리는 대신 보드에서 원하는 칸을 터치해 이동 (출발 칸을 지나면 월급) |
| 승리 | 최후의 1인. 라운드 제한 모드에서는 정해진 라운드 후 **총자산** 1위 |

**생일 카드**: 다른 사람의 현금 한도 안에서만 받습니다(남의 차례에 빚이 생기지 않도록).

### 시우 마블 벌칙 룰렛
- 룰렛(8칸, 소형 초록·중형 노랑·대형 빨강)이 확대 등장 → "터치하여 돌리기" → 3초 동안 점점 느려지며 멈춤(칸마다 틱 소리)
- **결과는 돌리기 전에 엔진이 확률로 미리 정하고**, 룰렛은 그 칸에 멈추도록 연출만 합니다.
  대형이면 마지막 1초 동안 룰렛 테두리가 붉게 빛나고 화면이 살짝 흔들립니다.
- 결과 칸 확대 → 벌칙 카드가 뒤집히며 내용 표시 → [확인] → 효과(돈 연출 등)
- 확률: 소형 60% / 중형 30% / 대형 10%. **총자산 꼴찌는 대형 3%**(차이는 소형에), **1위는 대형 15%**(차이는 소형에서). 동점이면 보정 없음
- 한 번의 벌칙으로 잃는 금액은 **총자산 × 25%** 를 넘지 않습니다
- 소형: 벌금 5만 / 뒤로 2칸 / 다음 턴 주사위 1개 / 다음 월급 절반
- 중형: 다른 생존자 모두에게 3만씩 / 다음 통행료 2배 / 1턴 쉬기 / 내 건물 1단계 철거(없으면 벌금 10만)
- 대형: 무인도 직행 / 보유 현금 20% 사회복지기금 기부 / 가장 비싼 땅을 판매가의 절반에 강제 매각(없으면 벌금 20만)
- **벌칙 면제권**(황금열쇠, 보관형)이 있으면 룰렛 전에 사용 여부를 묻습니다
- **현실 벌칙 모드**(마블 시작 팝업·마블 설정에서 켜기, 기본 끔): 대형 벌칙이 나오면 게임 벌칙과 함께
  공통 **대형** 현실 벌칙 문구 하나를 빨간 글씨로 표시 (문구는 허브 설정 → 벌칙 문구 편집)

### 다른 게임 (게임별 GameConfig)
각 게임의 수치는 `games/<폴더>/logic/src/main/kotlin/com/siwoo/party/games/<폴더>/GameConfig.kt` 한 파일에 모여 있습니다.
- `_MS`(밀리초)로 끝나는 **연출 시간**에는 실행할 때 설정의 연출 속도 배율(느리게 1.0 · 보통 0.7 · 빠르게 0.4)이 곱해집니다.
- 규칙에 해당하는 시간(반응속도 대기 `WAIT_*_MS`, 폭탄 심지 `FUSE_*_MS`, 줄다리기 `TUG_TIME_SEC`, 라이어 설명·토론 초,
  짝 맞추기 외울 시간 `MEMORY_MISMATCH_SHOW_MS`)과 확률·개수는 속도 설정과 상관없이 그대로 쓰입니다. (각 상수 주석에 표시)
- 바꾼 뒤에는 그 게임의 로직 테스트를 돌려 보세요: `./gradlew :games:<폴더>:logic:test`

## 5. 직접 빌드하기

필요한 것: JDK 17, Android SDK (Platform 34, Build-Tools 34.0.0) — Android Studio를 설치하면 함께 들어옵니다.

```bash
cd siwoo-party
./gradlew test -x testReleaseUnitTest   # 전체 테스트: 공통·11개 게임 로직 + 화면(Robolectric) + 허브 흐름

./gradlew :hub:checkNoNativeLibs    # 두 APK를 빌드하고 lib/(네이티브 라이브러리) 폴더가 없는지 검사
```

### 게임 추가하는 법
1. `games/<게임>/logic`(순수 Kotlin 규칙 + `GameConfig`) + `games/<게임>/ui`(Android 라이브러리) 폴더를 만듭니다
   — `settings.gradle.kts` 와 허브 의존성은 **폴더만 있으면 자동으로** 잡힙니다
2. `GameModule` 구현: id·이름·소개·인원·방식(동시 터치/차례대로)·**카테고리**(파티면 `partyTags`)·예상 시간·아이콘 그리기·규칙 카드 3장·시작 Activity
   (기울기 센서가 꼭 필요하면 `needsSensor`, 동시 터치 수가 다르면 `needsMultiTouch` — 랜덤 후보 거르기에 쓰임)
3. 게임 Activity 는 `PartyGameActivity` 를 상속: `players` 가 채워져 있고, 끝나면 `finishWithRanks(순위들)`.
   뒤로 가기·백그라운드 일시정지·규칙 보기는 자동, 시간은 `timers.after(t(ms))`, 동시 터치는 `MultiTouchZoneView`
4. `hub/.../GameRegistry.kt` 의 `games` 에 한 줄 → 카테고리 탭(또는 파티 존)·랜덤 설정에 자동으로 나옵니다
   (허브 테스트가 모든 게임을 2·3·4인 흐름·수명주기·목록 점검)

## 7. 점검

### 32비트(armeabi-v7a) 호환 · 네이티브 라이브러리
- 런타임 의존성: `kotlin-stdlib`, 프로젝트 모듈, `androidx.recyclerview`(+ androidx core/annotation 등). 모두 순수 Java/Kotlin 바이트코드로 `.so`가 없습니다.
- APK에 `lib/` 폴더가 없으면 ABI에 상관없이 설치·실행됩니다. `:hub:checkNoNativeLibs`와 CI가 빌드 때마다 확인합니다.
- minSdk 26 / targetSdk 34 / compileSdk 34, 가로 고정(sensorLandscape), 시스템 기본 폰트, **권한 없음**(인터넷 포함).
- APK 크기: 릴리스(R8 축소) 약 0.75MB (752KB), 디버그 약 3.2MB — 목표 12MB 이하. 외부 이미지·사운드·폰트 파일 없음 (카드·아이콘·판 모두 Canvas 코드 그림).

### 저사양 최적화
- **모든 게임**의 커스텀 View·그림 함수의 onDraw 경로에 객체 생성이 없음을 바이트코드로 확인 (그라데이션·경로·문구는 크기가 바뀔 때만 만듦).
- 애니메이션·물리·연타 루프는 움직임이 있을 때만 돌고, 멈추거나 일시정지하면 다시 그리지 않습니다. 파티 존 입구 빛은 하드웨어 레이어 알파만 바꿔(다시 그리기 없음) 화면을 떠나면 멈춥니다.
- 비트맵은 모두 종료 시 recycle: 마블 보드·알까기 판(RGB_565), 오목·사목 판 배경, 그림 맞히기 캔버스, **카드 비트맵 캐시**(원카드·도둑잡기·블랙잭이 끝날 때 `CardBitmaps.release()`).
- 그림 맞히기: 획은 비트맵에 바로 굽고 진행 중 획 1개만 Path 로 그림 (획 120개 상한, 65초 측정에서 프레임당 Path 생성 0).
- 센서: 윷놀이 흔들기·이마 퀴즈 기울기 모두 필요한 동안에만 등록, 일시정지·종료 시 해제. 센서가 없는 기기는 카드에 경고, 랜덤 후보에서 제외.
- 애니메이터·타이머는 `timers`(일시정지 시 멈춤, 종료 시 취소)로만 돌립니다. Context·View·Bitmap 을 static 으로 붙잡는 곳 없음.
- 메모리 목표(게임당 60MB, 허브·파티 존 40MB 이하)는 실제 기기에서 확인해야 합니다: 게임을 연 상태에서 `adb shell dumpsys meminfo com.siwoo.party` 의 TOTAL PSS.
  큰 메모리를 쓰는 것은 화면 크기 이하 판 비트맵(한 게임에 1장)과 카드 캐시(최대 55장, xhdpi 기준 약 3.8MB)뿐이고 나머지는 코드 그림입니다.
