# 시우 마블 (Siwoo Marble)

한 대의 안드로이드 폰을 돌려가며 2~4명이 함께 하는 **로컬 멀티(핫시트) 보드게임**입니다.
인터넷·광고·계정이 없고, 이미지·사운드 파일 없이 모든 그래픽을 코드(Canvas)로 그립니다.

- 대상: 안드로이드 8.0(API 26) 이상, 32비트 ARM(armeabi-v7a) 저사양 폰 포함
- 화면: **가로 고정**(기기를 어느 쪽으로 돌려도 가로 유지), 전체 화면
- 언어/구성: Kotlin + 커스텀 View(Canvas) (NDK·게임 엔진·Compose·AppCompat 없음, AndroidX 는 목록용 RecyclerView 만)
- 권한: **없음** (인터넷 권한도 요청하지 않음)

---

## 1. 설치 방법 (APK 직접 설치)

1. APK 파일(`app-release.apk` 권장)을 폰으로 옮깁니다. (USB, 메신저 "나에게 보내기", 구글 드라이브 등)
2. 폰의 **파일 관리자**(또는 다운로드 앱)에서 APK를 누릅니다.
3. "보안상의 이유로 이 출처의 앱을 설치할 수 없습니다" 같은 안내가 나오면 **설정**을 누르고
   **"이 출처 허용"** 스위치를 켭니다. (= 알 수 없는 출처 허용)
   - 안드로이드 8.0 이상은 앱별로 허용합니다.
     직접 찾아가려면: `설정 → 애플리케이션(앱) → 특별한 접근(특수 앱 접근) → 출처를 알 수 없는 앱 설치`
     → APK를 연 앱(예: 내 파일, Chrome)을 선택 → 허용
4. 뒤로 돌아와 **설치**를 누릅니다.
5. 설치가 끝나면 보안을 위해 3번에서 켠 허용을 다시 꺼도 됩니다.

> 디버그 키로 서명되어 있어 Play 프로텍트가 "확인되지 않은 앱" 경고를 띄울 수 있습니다.
> "무시하고 설치"(또는 "세부정보 → 설치")를 누르면 됩니다.
> 디버그 APK와 릴리스 APK는 같은 키로 서명되어 서로 덮어 설치할 수 있습니다.

### APK 받는 곳
- **GitHub Releases**: 저장소 오른쪽 **Releases** → 최신 `시우 마블 …` → `siwoo-marble-<버전>-release.apk`
  (폰 브라우저로 바로 내려받아 설치할 수 있습니다)
- **Actions**: `siwoo-marble/` 폴더가 바뀌어 push 될 때마다 자동 빌드되며, 실행 결과 하단
  **Artifacts → `siwoo-marble-apk`** 에서도 받을 수 있습니다.

새 릴리스 만들기: 커밋 메시지에 `[release]` 를 넣어 push 하거나,
Actions → "시우 마블 APK 빌드" → **Run workflow** (release 체크) 를 누르면
테스트·빌드 후 `siwoo-marble-v<버전>-build<번호>` 태그로 릴리스가 만들어지고 APK 두 개가 첨부됩니다.
버전은 `app/build.gradle.kts` 의 `versionName` / `versionCode` 에서 올립니다.

## 2. 게임 방법

### 시작
타이틀("시우 마블" / "시우 공방") → **게임 시작** → 아래에서 올라오는 팝업에서 **2인/3인/4인** →
같은 팝업에서 이름·말 색상(중복 불가)·게임 방식(최후 1인 / 15·20·30라운드)·현실 벌칙 설정 → **시작** →
순서 추첨 연출 후 게임이 시작됩니다. 저장된 게임이 있으면 타이틀에 **이어하기**가 나옵니다.

### 화면 (가로)
```
┌──────┬──────────────┬──────┐
│ P1   │   보드(정사각)  │ P2   │   패널: 말 색·이름·현재 돈·보유 땅 수·총자산·상태
│      │  가운데: 주사위 │      │   현재 차례 패널은 테두리가 천천히 빛나며 살짝 커짐
│ P3   │  + 중앙 문구    │ P4   │   벌칙 지속 효과는 작은 아이콘(주사위1·×2·½·쉼)
├──────┴──────────────┴──────┤
│ 알림 한 줄   [판매] [거래] [턴 종료] [설정] │  ← 행동 바 (현재 차례만, 연출 중 비활성)
└────────────────────────────┘
```
- **주사위는 보드 가운데를 직접 터치**해서 굴립니다. 굴릴 수 있을 때만 위아래로 떠오르며 "터치하여 굴리기"가 깜빡이고,
  아닐 때는 흐리게 보이고 터치가 무시됩니다.
- 패널을 누르면 그 사람의 보유 땅·건물·카드 상세가 나옵니다. 칸을 누르면 땅값·건설비·통행료 표가 나옵니다.

### 규칙
| 항목 | 규칙 |
|---|---|
| 주사위 | 2개의 합만큼 이동. **더블**이면 한 번 더(다시 굴려야 턴 종료 가능), **3연속 더블**이면 즉시 무인도 |
| 턴 종료 | 굴린 뒤 **[턴 종료]**를 눌러야 다음 사람 차례 (자동으로 넘어가지 않음) |
| 월급 | 출발 칸을 지나가거나 도착하면 20만 |
| 빈 땅 | 자동 팝업 없이 칸이 **금색으로 발광** + "터치하여 구매" → 칸을 터치해 구매 카드에서 [구매]. 사지 않고 [턴 종료]하면 포기. 돈이 모자라면 발광은 하지만 [구매]가 비활성화되고 "잔액 부족" |
| 내 땅 | 산 **다음 방문부터** 같은 방식(초록 발광)으로 별장 → 빌딩 → 호텔 한 단계씩 |
| 관광지 | 제주도·여객기·부산·여객선·우주선·서울: 구매만, 건물 불가, 고정 통행료 |
| 남의 땅 | 칸이 소유자 색으로 번쩍 → "통행료 수거!" → 코인이 내 패널에서 소유자 패널로. 통행료 면제권이 있으면 먼저 사용 여부를 묻습니다 |
| 돈 부족 | 전액을 내고 **마이너스**가 됩니다(받는 사람은 전액 받음). 마이너스면 [턴 종료]·주사위 비활성화, [판매]가 빨갛게 깜빡이며 "잔액이 부족합니다. 땅을 판매하거나 거래하세요" |
| 판매 | 내 땅을 여러 장 골라 은행에 판매. **판매가 = 자산 가치(땅값 + 지은 건물 건설비) × 50%** |
| 파산 | 땅·건물을 모두 팔아도 마이너스면 파산 (패널 흑백 + "파산" 도장, 땅은 은행으로) |
| 거래 | 상대를 골라 땅 여러 개 + 돈을 주고받는 제안 → 기기를 넘겨 상대가 수락/거절. **한 턴에 최대 3번** 제안 |
| 황금열쇠 | 16종(벌칙 면제권 포함). 카드가 뒤집히며 공개, 사용한 카드는 덱 맨 아래로 |
| 벌칙 칸 | 7번(아래 줄)·22번(위 줄). 빨갛게 3번 깜빡 → "벌칙 당첨!" → **벌칙 룰렛** (아래 참고) |
| 무인도 | 3턴 갇힘. 더블이면 즉시 탈출, 탈출권 카드 사용 가능 |
| 사회복지기금 | 접수처 칸(15만)·기부 카드로 쌓이고, 사회복지기금 칸에 도착한 사람이 전액 수령 |
| 우주여행 | 다음 턴에 굴리는 대신 보드에서 원하는 칸을 터치해 이동 (출발 칸을 지나면 월급) |
| 승리 | 최후의 1인. 라운드 제한 모드에서는 정해진 라운드 후 **총자산** 1위 |

**생일 카드**: 다른 사람의 현금 한도 안에서만 받습니다(남의 차례에 빚이 생기지 않도록).

### 벌칙 룰렛
- 룰렛(8칸, 소형 초록·중형 노랑·대형 빨강)이 확대 등장 → "터치하여 돌리기" → 3초 동안 점점 느려지며 멈춤(칸마다 틱 소리)
- **결과는 돌리기 전에 엔진이 확률로 미리 정하고**, 룰렛은 그 칸에 멈추도록 연출만 합니다.
  대형이면 마지막 1초 동안 룰렛 테두리가 붉게 빛나고 화면이 살짝 흔들립니다.
- 결과 칸 확대 → 벌칙 카드가 뒤집히며 내용 표시 → [확인] → 효과(돈 연출 등)
- 확률: 소형 60% / 중형 30% / 대형 10%. **총자산 꼴찌는 대형 3%**(차이는 소형에), **1위는 대형 15%**(차이는 소형에서). 동점이면 보정 없음
- 한 번의 벌칙으로 잃는 금액은 **총자산 × 25%** 를 넘지 않습니다
- 소형: 벌금 5만 / 뒤로 2칸 / 다음 턴 주사위 1개 / 다음 월급 절반
- 중형: 다른 생존자 모두에게 3만씩 / 다음 통행료 2배 / 1턴 쉬기 / 내 건물 1단계 철거(없으면 벌금 10만)
- 대형: 무인도 직행 / 보유 현금 20% 사회복지기금 기부 / 가장 비싼 땅을 판매가의 절반에 강제 매각(없으면 벌금 20만)
- **벌칙 면제권**(황금열쇠, 보관형)이 있으면 룰렛 전에 사용 여부를 묻습니다
- **현실 벌칙 모드**(설정·시작 팝업에서 켜기, 기본 끔): 대형 벌칙이 나오면 게임 벌칙과 함께 현실 벌칙 문구도 표시.
  문구는 시작 팝업의 [문구 편집]에서 추가/수정/삭제 (기본 5개, 앱 내부 저장)

### 설정
연출 속도 **느리게(1.0배, 기본) / 보통(0.7배) / 빠르게(0.4배)**, 현실 벌칙, 효과음, 타이틀로, 새 게임.
자동 저장: 매 행동 후와 앱이 백그라운드로 갈 때(진행 중인 연출은 즉시 정리하고 상태만 보존).

## 3. 수치 바꾸기 (GameConfig)

모든 공통 수치는 `core/src/main/kotlin/com/siwoo/marble/GameConfig.kt` 한 파일에 있습니다. 금액 단위는 **원**입니다.

| 상수 | 기본값 | 의미 |
|---|---|---|
| `START_MONEY` / `SALARY` | 3,000,000 / 200,000 | 시작 자금 / 월급 |
| `MAX_DOUBLES` / `ISLAND_TURNS` | 3 / 3 | 연속 더블 무인도행 / 무인도 턴 |
| `WELFARE_DONATION` | 150,000 | 사회복지기금 접수처 기부금 |
| `SELL_RATE` | 0.5 | 판매가 = 자산 가치 × 이 값 |
| `MAX_TRADES_PER_TURN` | 3 | 한 턴 거래 제안 횟수 |
| `TRADE_STEP_SMALL` / `BIG` | 10,000 / 100,000 | 거래 돈 입력 버튼 단위 |
| `PENALTY_SMALL/MEDIUM/LARGE_PCT` | 60 / 30 / 10 | 벌칙 등급 확률(%) |
| `PENALTY_LARGE_PCT_LAST` / `_FIRST` | 3 / 15 | 꼴찌 / 1위의 대형 확률 |
| `PENALTY_MAX_RATE` | 0.25 | 한 번의 벌칙 손실 상한 = 총자산 × 이 값 |
| `TURN_LIMIT_OPTIONS` | 0, 15, 20, 30 | 라운드 제한 선택지 (0 = 최후 1인) |
| `DICE_ROLL_MS` | 1200 | 주사위 굴림 |
| `DICE_RESULT_HOLD_MS` | 700 | 결과 숫자 보여주는 시간 |
| `MOVE_START_DELAY_MS` | 500 | 결과 후 이동 시작까지 |
| `STEP_MS` | 300 | 말 한 칸 이동 |
| `ARRIVE_PAUSE_MS` | 500 | 도착 후 효과 전 멈춤 |
| `MONEY_ANIM_MS` | 1200 | 코인 이동 / 숫자 변화 |
| `CENTER_BANNER_MS` | 1800 | 중앙 문구 |
| `TURN_CHANGE_MS` | 1500 | 차례 전환 화면 |
| `CARD_FLIP_MS` | 900 | 황금열쇠·벌칙 카드 뒤집기 |
| `JUMP_MS` / `TILE_FLASH_MS` / `PENALTY_FLASH_MS` / `ROULETTE_SPIN_MS` | 700 / 600 / 1200 / 3000 | 순간이동 / 통행료 번쩍 / 벌칙 칸 깜빡 / 룰렛 회전 |
| `SPEED_FACTORS` | 1.0, 0.7, 0.4 | 설정의 연출 속도 배율 (모든 연출 시간에 곱함) |

칸별 수치·카드·벌칙은 따로 있습니다.
- **땅값·건설비·통행료**: `data/BoardData.kt` — `city(칸, 이름, 표시이름, 색그룹, 땅값, build(별장, 빌딩, 호텔), toll(땅, 별장, 빌딩, 호텔))`
- **황금열쇠**: `data/CardData.kt`
- **벌칙 목록·룰렛 칸 배치**: `data/PenaltyData.kt`
- **색상 팔레트**(배경·카드·금색·빨강/초록·플레이어 4색): `app/.../ui/Theme.kt`

수치를 바꾼 뒤에는 `./gradlew :core:test`로 규칙 테스트를 돌려 보세요
(일부 테스트는 기본 수치로 계산하므로, 금액을 바꾸면 해당 테스트의 기대값도 고쳐야 할 수 있습니다).

## 4. 직접 빌드하기

필요한 것: JDK 17, Android SDK (Platform 34, Build-Tools 34.0.0) — Android Studio를 설치하면 함께 들어옵니다.

```bash
cd siwoo-marble
./gradlew :core:test               # 규칙 엔진 단위 테스트 (SDK 없이: ./gradlew -PcoreOnly :core:test)
./gradlew :app:testDebugUnitTest   # UI 흐름 테스트 (Robolectric)
./gradlew assembleDebug            # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease          # app/build/outputs/apk/release/app-release.apk (R8 축소, 디버그 키 서명)
./gradlew :app:checkNoNativeLibs   # 두 APK를 빌드하고 lib/(네이티브 라이브러리) 폴더가 없는지 검사
```

## 5. 프로젝트 구조

```
siwoo-marble/
├─ core/  (순수 Kotlin, Android 의존성 없음 → PC에서 바로 테스트)
│  └─ com/siwoo/marble/
│     ├─ GameConfig.kt          모든 공통 수치 (금액·확률·연출 시간)
│     ├─ model/  Tile, Player, Card, Penalty, GameState(TradeOffer·Pending·OfferKind)
│     ├─ logic/  GameEngine(규칙 전담), Dice, GameEvent(연출용 이벤트), Money(천 단위 콤마)
│     └─ data/   BoardData(40칸), CardData(황금열쇠 16), PenaltyData(벌칙 11·룰렛 8칸), SaveCodec·Json
│  └─ test/      GameEngineTest (56개)
└─ app/   (안드로이드)
   ├─ ui/ TitleActivity       타이틀·인원 팝업·이름/색·현실 벌칙 문구 편집·순서 추첨
   │      MainActivity        게임 화면: 이벤트 → 연출 큐, 팝업, 판매·거래·룰렛 흐름
   │      GameLayout          가로 배치 계산 (보드·좌우 패널·행동 바)
   │      BoardView           보드 캐시 비트맵·깃발·건물·발광·주사위·말 (Canvas)
   │      PlayerPanelView     플레이어 패널 (돈 카운트·빛나는 테두리·파산 도장·벌칙 아이콘)
   │      FxView / FxQueue    코인·카드 파티클(풀 20개)·중앙 문구 / 연출 큐
   │      SellSheet / TradeSheet / LandItemView / BalanceView / MoneyStepper   판매·거래 화면
   │      RouletteView / KeyCardView   벌칙 룰렛 / 황금열쇠·벌칙 카드 뒤집기
   │      PopupLayer / GameButton / Theme / GameStorage / Beeper / Immersive
   └─ test/ UiFlowTest         가로 배치 겹침·연출 큐 순서·실제 버튼 자동 플레이 (Robolectric)
```

`GameEngine`은 UI를 전혀 모릅니다. UI가 `roll()`, `buy()`, `build()`, `sell()`, `trade()`, `spinPenalty()`, `endTurn()` 등을 부르면
엔진이 규칙을 처리하고 `GameEvent` 목록을 돌려주며, 화면은 그것을 **연출 큐**로 하나씩 순서대로 재생합니다.
화면에 보이는 돈·소유 표시는 연출 순서대로 바뀌고(코인 도착 → 깃발), 큐가 끝나면 실제 상태와 다시 맞춥니다.

## 6. 점검 결과

### 32비트(armeabi-v7a) 호환 · 네이티브 라이브러리
- 런타임 의존성: `kotlin-stdlib`, `:core`, `androidx.recyclerview`(+ androidx core/annotation 등). 모두 순수 Java/Kotlin 바이트코드로 `.so`가 없습니다.
- APK에 `lib/` 폴더가 없으면 ABI에 상관없이(armeabi-v7a/arm64/x86) 설치·실행됩니다. `:app:checkNoNativeLibs`와 CI가 빌드 때마다 확인합니다.
- minSdk 26 / targetSdk 34 / compileSdk 34, 가로 고정(sensorLandscape), 시스템 기본 폰트, **권한 없음**.

### 저사양 최적화
- 보드 배경(칸·이름·가격·색 띠·안쪽 그림자·모서리 아이콘·제목)은 **RGB_565 비트맵 1장**으로 캐시, 매 프레임에는 깃발·건물·발광·말·주사위만.
- 발광은 블러 없이 **RadialGradient 셰이더를 한 번만 만들고** 위치(Matrix)와 알파만 바꿉니다. 패널·룰렛의 빛도 두께·알파가 다른 테두리 몇 겹.
- 코인·카드 파티클은 **최대 20개 객체 풀** 재사용.
- 커스텀 View 7종(BoardView, FxView, PlayerPanelView, RouletteView, LandItemView, BalanceView, GameButton)의 onDraw 경로에
  객체 생성이 없음을 컴파일된 바이트코드에서 확인(`new` 0개).
- 애니메이션은 ValueAnimator, 진행 중일 때만 다시 그립니다. 상시 연출(떠오르는 주사위·발광·깜빡임)은 필요할 때만 약 30fps로.
- 판매/거래 목록은 RecyclerView. 릴리스는 R8 축소 + 리소스 축소.
