# 시우 마블 (Siwoo Marble)

한 대의 안드로이드 폰을 돌려가며 2~4명이 함께 하는 **로컬 멀티(핫시트) 보드게임**입니다.
인터넷·광고·계정이 없고, 이미지·사운드 파일 없이 모든 그래픽을 코드(Canvas)로 그립니다.

- 대상: 안드로이드 8.0(API 26) 이상, 32비트 ARM(armeabi-v7a) 저사양 폰 포함
- 언어/구성: Kotlin + 커스텀 View(Canvas)만 사용 (NDK·게임 엔진·Compose·AppCompat 없음)
- 권한: **없음** (인터넷 권한도 요청하지 않음)

---

## 1. 설치 방법 (APK 직접 설치)

1. APK 파일(`app-release.apk` 권장)을 폰으로 옮깁니다. (USB, 메신저 "나에게 보내기", 구글 드라이브 등)
2. 폰의 **파일 관리자**(또는 다운로드 앱)에서 APK를 누릅니다.
3. "보안상의 이유로 이 출처의 앱을 설치할 수 없습니다" 같은 안내가 나오면 **설정**을 누르고
   **"이 출처 허용"** 스위치를 켭니다. (= 알 수 없는 출처 허용)
   - 안드로이드 8.0 이상은 앱별로 허용합니다.
     직접 찾아가려면: `설정 → 애플리케이션(앱) → 특별한 접근(특수 앱 접근) → 출처를 알 수 없는 앱 설치`
     → APK를 연 앱(예: 내 파일, Chrome)을 선택 → 허용
4. 뒤로 돌아와 **설치**를 누릅니다.
5. 설치가 끝나면 보안을 위해 3번에서 켠 허용을 다시 꺼도 됩니다.

> 디버그 키로 서명되어 있어 Play 프로텍트가 "확인되지 않은 앱" 경고를 띄울 수 있습니다.
> "무시하고 설치"(또는 "세부정보 → 설치")를 누르면 됩니다.
> 디버그 APK와 릴리스 APK는 같은 키로 서명되어 서로 덮어 설치할 수 있습니다.

### APK 받는 곳
- **GitHub Releases**: 저장소 오른쪽 **Releases** → 최신 `시우 마블 …` → `siwoo-marble-<버전>-release.apk`
  (폰 브라우저로 바로 내려받아 설치할 수 있습니다)
- **Actions**: `siwoo-marble/` 폴더가 바뀌어 push 될 때마다 자동 빌드되며, 실행 결과 하단
  **Artifacts → `siwoo-marble-apk`** 에서도 받을 수 있습니다.

새 릴리스 만들기: 커밋 메시지에 `[release]` 를 넣어 push 하거나,
Actions → "시우 마블 APK 빌드" → **Run workflow** (release 체크) 를 누르면
테스트·빌드 후 `siwoo-marble-v<버전>-build<번호>` 태그로 릴리스가 만들어지고 APK 두 개가 첨부됩니다.
버전은 `app/build.gradle.kts` 의 `versionName` / `versionCode` 에서 올립니다.

## 2. 게임 방법

| 항목 | 규칙 |
|---|---|
| 시작 | 인원(2~4)·이름·말 색상 선택 → 순서 무작위, 모두 같은 시작 자금(300만) |
| 주사위 | 2개를 굴려 합만큼 이동. **더블**이면 한 번 더, **3연속 더블**이면 즉시 무인도 |
| 월급 | 출발 칸을 지나가거나 도착하면 20만 |
| 빈 땅 | 구매 여부 선택 |
| 내 땅 | 산 **다음 방문부터** 별장 → 빌딩 → 호텔 순으로 한 번에 1단계 건설 |
| 관광지 | 제주도·여객기·부산·여객선·우주선·서울: 구매만 가능, 건물 불가, 고정 통행료 |
| 남의 땅 | 통행료 지불 (통행료 면제권이 있으면 사용 여부 선택) |
| 황금열쇠 | 15종 카드. 사용한 카드는 덱 맨 아래로 |
| 무인도 | 3턴 갇힘. 더블이 나오면 즉시 탈출, 탈출권 카드 사용 가능 |
| 사회복지기금 | 접수처 칸(15만)·기부 카드로 쌓이고, 사회복지기금 칸에 도착한 사람이 전액 수령 |
| 우주여행 | 다음 턴에 보드에서 원하는 칸을 터치해 바로 이동 (출발 칸을 지나면 월급) |
| 돈 부족 | 땅·건물을 은행에 구매가의 절반에 매각해 지불 (직접 고르거나 "자동 매각") |
| 파산 | 다 팔아도 못 내면 파산. 남은 돈은 받을 사람에게, 땅은 모두 은행으로 |
| 승리 | 최후의 1인. "라운드 제한" 모드에서는 정해진 라운드 후 **총자산(현금+땅+건물)** 1위 |

**자동 매각 순서**: ① 건물부터, 매각가가 가장 싼 건물을 1단계씩 → ② 건물이 없어지면 땅값이 가장 싼 땅부터.
(비싼 땅을 최대한 오래 지키는 순서. 파산 정리도 같은 순서)

**생일 카드**: 다른 사람에게서 정해진 금액을 받되, 그 사람이 가진 현금 한도 안에서만 받습니다.
(남의 차례에 강제 매각이 일어나지 않도록 한 규칙)

### 화면
- **모서리 자산 카드** (모두의 마블 스타일): 보드 바깥 네 모서리에 플레이어마다 카드 1장
  (차례 순서대로 왼쪽 위 → 오른쪽 위 → 오른쪽 아래 → 왼쪽 아래, 2인은 대각선).
  말 색 아이콘·이름·현금·총자산·무인도/우주여행/보관 열쇠 표시, 차례인 사람은 테두리 강조, 총자산 단독 선두는 `1위`, 파산은 흐리게.
  카드를 누르면 보유 땅·건물·카드 상세 현황
- 가운데: 보드(정사각형). **칸을 터치**하면 땅값·건설비·단계별 통행료·소유자 팝업
- 아래: 현재 차례 정보, 최근 기록, 큰 **주사위 굴리기** 버튼
- 턴이 바뀌면 **"○○님 차례"** 화면이 보드를 가리고, 기기를 받은 사람이 확인을 눌러야 시작
- **설정**: 말 이동 빠르게, 효과음 끄기, 새 게임
- 자동 저장: 매 행동(턴 종료 포함) 후, 그리고 앱이 백그라운드로 갈 때. 다시 켜면 **이어하기 / 새 게임** 선택

## 3. 수치 바꾸기 (GameConfig)

모든 공통 수치는 `core/src/main/kotlin/com/siwoo/marble/GameConfig.kt` 한 파일에 있습니다.
금액 단위는 **원**입니다 (화면에는 `30만`처럼 표시).

| 상수 | 기본값 | 의미 |
|---|---|---|
| `START_MONEY` | 3_000_000 | 시작 자금 |
| `SALARY` | 200_000 | 출발 칸 통과/도착 월급 |
| `MAX_DOUBLES` | 3 | 이 횟수만큼 연속 더블이면 무인도행 |
| `ISLAND_TURNS` | 3 | 무인도에 갇히는 턴 수 |
| `WELFARE_DONATION` | 150_000 | 사회복지기금 접수처 기부금 |
| `SELL_BACK_PERCENT` | 50 | 은행 매각 시 돌려받는 비율(%) |
| `TURN_LIMIT_OPTIONS` | 0, 15, 20, 30 | 설정 화면의 라운드 제한 선택지 (0 = 최후 1인까지) |
| `DEFAULT_TURN_LIMIT` | 0 | 기본 선택 |
| `MOVE_STEP_MS` / `MOVE_STEP_FAST_MS` | 120 / 45 | 말 이동 한 칸당 시간(ms), 보통/빠르게 |
| `DICE_ROLL_MS` / `DICE_ROLL_FAST_MS` | 550 / 250 | 주사위 연출 시간(ms) |
| `PLAYER_COLORS` | 6색 | 고를 수 있는 말 색상 |

칸별 수치와 카드는 따로 있습니다.

- **땅값·건설비·통행료**: `core/src/main/kotlin/com/siwoo/marble/data/BoardData.kt`
  ```kotlin
  // city(칸번호, 이름, 보드표시이름, 색그룹, 땅값, build(별장, 빌딩, 호텔), toll(땅, 별장, 빌딩, 호텔))
  city(1, "타이베이", "타이베이", 0, 50_000, build(20_000, 50_000, 80_000), toll(5_000, 25_000, 75_000, 150_000)),
  // special(칸번호, 이름, 보드표시이름, 땅값, 고정통행료)
  special(39, "서울", "서울", 1_000_000, 2_000_000),
  ```
- **황금열쇠 카드**: `core/src/main/kotlin/com/siwoo/marble/data/CardData.kt`
  (`Card(id, 제목, 설명, 효과, 금액…)` — 금액만 바꾸거나 같은 형식으로 카드를 추가/삭제)

수치를 바꾼 뒤에는 `./gradlew :core:test`로 규칙 테스트를 돌려 보세요.
(테스트 일부는 기본 수치를 기준으로 계산하므로, 금액을 바꾸면 해당 테스트의 기대값도 함께 고쳐야 할 수 있습니다)

## 4. 직접 빌드하기

필요한 것: JDK 17, Android SDK (Platform 34, Build-Tools 34.0.0) — Android Studio를 설치하면 함께 들어옵니다.

```bash
cd siwoo-marble
./gradlew :core:test              # 규칙 엔진 단위 테스트 (Android SDK 불필요: -PcoreOnly 를 붙이면 SDK 없이도 실행)
./gradlew assembleDebug           # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease         # app/build/outputs/apk/release/app-release.apk (R8 축소, 디버그 키 서명)
./gradlew :app:checkNoNativeLibs  # 두 APK를 빌드하고 lib/(네이티브 라이브러리) 폴더가 없는지 검사
```

Android SDK가 없는 PC에서 규칙 엔진만 테스트하려면: `./gradlew -PcoreOnly :core:test`

## 5. 프로젝트 구조

```
siwoo-marble/
├─ core/  (순수 Kotlin, Android 의존성 없음 → PC에서 바로 테스트)
│  └─ com/siwoo/marble/
│     ├─ GameConfig.kt          모든 공통 수치
│     ├─ model/  Tile, Player, Card, GameState (순수 데이터)
│     ├─ logic/  GameEngine(규칙 전담), Dice, GameEvent, Money
│     └─ data/   BoardData(40칸), CardData(황금열쇠), SaveCodec·Json(저장)
│  └─ test/      GameEngineTest (33개)
└─ app/   (안드로이드)
   └─ com/siwoo/marble/ui/
      ├─ SetupActivity    이어하기/새 게임, 인원·이름·색상·라운드 제한
      ├─ MainActivity     게임 화면, 이벤트 재생, 다이얼로그, 턴 넘김 화면
      ├─ PlayerCardView   보드 바깥 모서리의 플레이어 자산 카드
      ├─ BoardView        보드·말·건물·주사위 그리기 (Canvas)
      ├─ GameDialog       큰 버튼 다이얼로그
      ├─ GameStorage      내부 저장소 JSON 저장, 설정
      ├─ Beeper           ToneGenerator 효과음
      └─ Ui               색·크기·위젯 도우미
```

`GameEngine`은 UI를 전혀 모릅니다. UI가 `roll()`, `answer()`, `spaceTravel()`, `sellBuilding()` 등을 호출하면
엔진이 규칙을 처리하고 `GameEvent` 목록(주사위·이동·메시지…)을 돌려주며, 화면은 그것을 순서대로 재생하기만 합니다.

## 6. 점검 결과

### 빌드 결과 (GitHub Actions, 공식 Android SDK 34)
| APK | 크기 | lib/ 항목 | 권한 |
|---|---|---|---|
| app-release.apk (R8) | 약 60 KB | 0 | 0 |
| app-debug.apk | 약 0.9 MB | 0 | 0 |

### 32비트(armeabi-v7a) 호환 · 네이티브 라이브러리
- 의존성은 `kotlin-stdlib`(+ `org.jetbrains:annotations`)와 `:core` 모듈뿐입니다. 모두 순수 JVM 바이트코드이며 `.so`가 없습니다.
  AndroidX·AppCompat·Coroutines도 쓰지 않습니다.
- APK에 `lib/` 폴더가 없으면 ABI에 상관없이(armeabi-v7a/arm64/x86) 그대로 설치·실행됩니다.
  `:app:checkNoNativeLibs` 작업과 CI가 빌드 때마다 이를 확인합니다.
- minSdk 26 / targetSdk 34 / compileSdk 34, 세로 고정, 시스템 기본 폰트, 인터넷 등 **권한 없음**.

### 저사양 최적화
- 보드 배경(칸·이름·가격·색 띠·모서리 그림·제목)은 크기가 정해질 때 **RGB_565 비트맵 1장**(보드 크기 이하)으로 미리 그림.
  매 프레임은 비트맵 + 소유 표시 + 건물 + 말 + 주사위만 그립니다.
- `onDraw()`와 그 하위 함수에는 객체 생성이 없습니다 (Paint·RectF·Path·문자열은 필드로 재사용,
  컴파일된 바이트코드에서 `new` 명령이 0개임을 확인).
- `invalidate()`는 애니메이션 중(ValueAnimator 갱신)과 상태가 바뀔 때만 호출합니다.
- 하드웨어 가속 사용, 게임 화면 창 배경 제거, "○○님 차례" 화면이 떠 있는 동안 뒤의 보드는 그리지 않음.
- 릴리스 빌드: R8 축소 + 리소스 축소.
- 앱이 백그라운드로 가면 진행 중인 애니메이션은 즉시 정리하고, 남은 연출은 기록만 남긴 채 상태를 저장합니다.

### 테스트
- `core` JVM 단위 테스트 33개: 3연속 더블, 무인도(더블 탈출/3턴/탈출권), 파산·매각 순서,
  출발 통과/도착 월급, 우주여행 이동, 사회복지기금 누적/수령, 건설 규칙, 통행료·면제권, 카드 덱 순환,
  턴 제한 승리, 저장/불러오기, 무작위 200판 끝까지 진행(불변식 검사) 등.
