## 2. 차량 물리 방식

### 2-1. 방식 요약

| 항목 | 현재 방식 | 비고 |
|---|---|---|
| 모델 | **운동학 자전거 모델** (질량·타이어 미끄러짐 없음) | `yawRate = v · tan(steer) / 축거` |
| 속도 | 1차원 스칼라 v(m/s) 하나 | 옆미끄러짐·드리프트 없음 |
| 적분 | 프레임당 2회 서브스텝 (dt 최대 0.05s) | |
| 질량 | **없음**. 승객 수가 가속에 영향 없음 | Unity에서 추가 대상 |
| 경사 | **없음** (평지) | 언덕 맵이면 새로 필요 |
| 서스펜션 | 없음. 차체 피치/롤은 가속도로 흉내 낸 연출 | |
| 충돌 | 버스를 원 n개(길이/2.2)로 근사 → 원·회전 박스 충돌체에서 밀어냄, 속도 ×0.2 | |
| 도로 이탈 | 가장 가까운 도로 중심에서 4.8m 넘으면 off-road (터미널 마당 예외) | |

### 2-2. 종방향(가속·감속) 수식

```
구동 a = thr × acc × gearK × max(0, 1 − (kmh / maxV)³)
         gearK = 1.25 − 0.1 × 단수   (전기버스는 1)
         R 기어 maxV = 12 km/h
         변속 중(shiftT > 0) thr × 0.25
저항   = 구름 0.1 (+ off-road 1.0) + 공기 0.00038·v² + 엔진브레이크 0.25(기어 물리고 액셀 0일 때)
제동   = brk × brake + 주차 5 + 도어 6      (m/s², 속도 0에서 멈춤, 역주행 안 함)
```

### 2-3. 자동 변속

| 항목 | 값 |
|---|---|
| 업시프트 | `kmh > gears[현재단] × 0.9` 이고 액셀 > 0.1 |
| 다운시프트 | `kmh < gears[아래단] × 0.55` |
| 변속 지연 | 업 0.45s / 다운 0.25s (전기버스 0) |
| RPM | 시동 꺼짐 0 / N·P·문열림 `700 + thr×1500` / 주행 `650 + (단내 진행률 0~1.15)×1650` → 최대 ≈ 2,550 |
| 계기판 RPM | 2,600 기준 원호, 2,200 넘으면 빨강 |

### 2-4. 조향

| 항목 | 값 |
|---|---|
| 최대 조향각(앞바퀴) | 정지 0.62 rad(35.5°) → 85 km/h에서 0.10 rad(5.7°), `pow(kmh/85, 0.7)` 보간 |
| 감기는 속도 | 0.75 rad/s(저속) → 0.40 rad/s(70 km/h) |
| 풀리는 속도 | 0.9 rad/s + 최대 0.6 (30 km/h에서 최대) |
| 화면 핸들 회전 | 앞바퀴 각 × 7 → 최대 ±249° (실차 ±450~630°보다 작음) |
| 키보드 조향 | 누르면 1.6/s로 감김, 떼면 3/s로 복귀 |
| 패드 조향 | 데드존 0.12, 곡선 `0.45x + 0.55x^2.4`, 스무딩 9/s |

| 2 | 2 | 꼭대기리 | loop→branch→ring→branch→loop (≈3.6km) | 9 | 1,650 | 380,000 | 1~4 | 2,000,000 | 3 | 회전 교차로 |
| 3 | 장 | 장날 특별 | 1번과 같음 | 7 | 1,450 | 330,000 | 3~8 (+시장·터미널 4) | 4,000,000 | 7 | 할머니·닭 40% |
| 4 | 막 | 막차 | 2번과 같음 | 9 | 1,850 | 520,000 | 0~3 | 7,000,000 | 12 | 밤, 학생 → 아저씨 |

첫 정류장은 대기 승객 +2. 목적지는 뒤쪽 정류장 중 `pow(rand, 0.8)` 분포로 뽑음.

### 5-2. 운행 1회 정산 공식

| 항목 | 계산 |
|---|---|
| 운임 수입 | 탑승 1명마다 노선 요금 |
| 군 보조금 | `노선 보조금 × (0.5 + 정시성/200)` → 50~100% |
| 우수 운행 보너스 | 별 4개 이상이면 `보조금 × 0.25` |
| 군수 | VIP 점수 > 0 → +200,000 / < 0 → −100,000 |
| 연료비 | `주행 km × 버스 연료비/km` |
| 수리비 | 충돌 누적 피해 (충돌속도 × 40,000) |
| 벌금 | 3-1 합계 |
| **순이익** | 위를 모두 더하고 뺀 값 → money에 반영 |
| 평판 | `rep += 별 − 2` (★1이면 −1, ★5면 +3) |

테스트 실측: 1번 노선 ★5 운행 ≈ 순이익 300,000원.

### 5-3. 진행 구조

| 화면 | 내용 |
|---|---|
| 시우 공방 로고 → 타이틀 | 이어하기 / 새로 시작 / 조작법 |
| 인트로 | 군수·현태 대사 7컷 |
| 본사(HQ) | 탭 4개: 운행(노선 선택·인수) / 차고(버스 구입·선택·도색) / 기록(통계·별점) / 조작법 |
| 운행 | 위 1~4 |
| 일시정지 | 계속 / 조작법 / 운행 포기 |
| 정산 | 4개 점수, 수입·지출 표, 지적 사항 → 차고로 |

**없는 것:** 기사 고용, 버스 노후/정비, 대출, 노선 배차, 시간 흐름(요일·계절), 여러 대 동시 운행.
→ 지시서 6단계의 "기사"는 HTML에 없는 **신규 기능**이다.
