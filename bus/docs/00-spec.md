# 프로젝트: '현태의 시골버스' HTML → Unity 이전 + 시내 맵 + 휠 포스피드백

## 배경
- 현태 시리즈 B급 감성의 본격 버스 시뮬레이터. 지금은 HTML(브라우저) 3D 게임.
- 현재 문제: 맵이 일자 도로뿐이라 운전 재미가 없음. 포스피드백도 브라우저에서는 불가능.
- 목표: Unity로 옮기고, 실제 시골 읍내처럼 생긴 맵을 만들고, 레이싱 휠 포스피드백(FFB)을 구현한다.

## 기존 기능 (반드시 유지)
- 3D 운전석 1인칭 시점
- 자동 변속 + 실감 기능 (기존 HTML 코드에 있는 것 전부)
- 운행 + 회사 경영 구조
- 키보드 / 게임패드 둘 다 지원
- 배경: 계란리와 무관한 새 시골 동네

## 내 장비 (테스트 기준)
- 휠: MOZA R3 (다이렉트 드라이브, PC, DirectInput FFB 지원, Pit House에서 조향각 설정)
- 페달: MOZA SR-P Lite 2페달 (나중에 클러치 추가 가능)
- 시프터: Thrustmaster TH8S (H패턴 7+R, USB)

## 작업 규칙
- 아래 단계를 순서대로 진행하고, 각 단계가 끝날 때마다 멈추고 결과 요약 + 내가 테스트할 방법을 알려줘. 내가 OK해야 다음 단계로.
- 단계마다 git 커밋.
- 모르는 부분(라이브러리 최신 상태, API 등)은 추측하지 말고 확인하고 진행.
- 모든 수치(조향각, FFB 세기, 기어비 등)는 하드코딩하지 말고 설정 파일이나 ScriptableObject로 빼서 내가 조절할 수 있게.

## 1단계: 기존 HTML 코드 분석
- 기존 HTML/JS 코드를 전부 읽고 기능 목록, 차량 물리 방식, 수치(속도, 가속, 기어 등), 경영 시스템 데이터 구조를 표로 정리.
- Unity로 옮길 때 그대로 옮길 것 / 다시 짜야 할 것을 구분해서 보여줘.

## 2단계: Unity 프로젝트 세팅
- Unity 6 (LTS), URP.
- 입력: 새 Input System (키보드, 게임패드) + 휠은 DirectInput 별도 처리 (5단계).
- 폴더 구조, 씬 구성(메인메뉴 / 운행 / 경영) 제안 후 생성.

## 3단계: 버스 주행 이전
- 기존 차량 물리를 Unity로 옮긴다. 버스는 무겁고 회전 반경이 크고 가속이 느리게.
- WheelCollider 또는 커스텀 물리 중 버스에 더 적합한 쪽을 이유와 함께 고르기.
- 운전석 시점 카메라, 계기판, 사이드미러, 문 개폐, 정류장 정차 판정.
- 변속: 자동(기본) + 수동 H패턴 모드(TH8S용, 클러치 없으면 자동 클러치) 선택 가능.

## 4단계: 시골 읍내 맵 (가장 중요)
일자 도로가 아니라 실제 한국 시골 읍내처럼:
- 읍내 중심가: 격자에 가까운 좁은 도로, 신호등 교차로 3~4곳, 시장, 터미널, 학교, 농협, 우체국
- 외곽: 2차선 시골길, 완만한 커브와 언덕, 논밭 사이 길, 다리, 굽은 산길 한 구간
- 노면 종류: 아스팔트 / 시멘트 / 비포장 / 과속방지턱 (FFB에서 쓸 수 있게 태그 지정)
- 정류장 12~15개, 노선 2~3개 (읍내 순환, 읍내↔마을 왕복 등)
- 도로는 Unity Splines 패키지 기반으로 만들어서 나중에 내가 쉽게 늘리고 고칠 수 있게
- AI 차량 소량 + 신호 준수, 승객 승하차
- 그래픽: 로우폴리 B급 감성, 성능 가볍게
- 먼저 맵 설계도(도로 배치, 노선, 정류장 위치)를 텍스트나 이미지로 보여주고 내가 OK하면 제작

## 5단계: 휠 입력 + 포스피드백
- DirectInput으로 MOZA R3 조향/페달, TH8S 기어 입력 받기. Unity용 DirectInput+FFB 오픈소스(예: Unity-DirectInput)가 있으면 최신 상태와 라이선스를 확인하고 사용, 없으면 대안 제시.
- 축 매핑, 데드존, 페달 커브 설정 화면 (키 재할당 포함).
- 조향각: 설정값(기본 900°)과 Pit House 설정이 같아야 1:1이 되도록 안내 문구 + 화면상 핸들 회전 1:1 동기화.
- FFB 효과 (각각 세기 슬라이더 + 전체 세기):
  1. 복원력: 속도와 조향각에 비례해서 중앙으로 돌아오는 힘
  2. 저속 무거움: 정차/저속일 때 강한 댐퍼 (버스 특유의 묵직함)
  3. 노면 진동: 노면 태그별로 다른 진동 (비포장 거칠게, 과속방지턱 툭)
  4. 충돌 충격: 부딪힌 방향으로 순간 튀는 힘
  5. 엔진 아이들링 미세 진동 (아주 약하게, 끌 수 있게)
- 일시정지, 메뉴, 게임 종료 시 FFB 반드시 0으로. 휠 연결 끊김 처리.
- 휠이 없으면 키보드/게임패드로 자동 전환.

## 6단계: 경영 시스템 이전
- 기존 HTML 경영 로직(돈, 버스 구매, 노선, 기사 등)을 Unity로 이전, 새 맵의 노선과 연결.
- 저장/불러오기.

## 7단계: 마무리 점검
- 키보드 / 게임패드 / 휠 세 가지로 각각 한 바퀴 운행 테스트 체크리스트 작성.
- 성능 확인 (RTX 4060 Ti 기준 60fps 이상), 빌드(Windows exe).
